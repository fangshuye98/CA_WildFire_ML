METHODOLOGY DOCUMENTATION
Spatiotemporal Neural Hurdle Model for Wildfire Burn Prediction
California 0.1° Monthly Grid  |  GRIDMET 1991–2024
================================================================================

1. MOTIVATION & PROBLEM FRAMING
────────────────────────────────
Wildfire prediction at a monthly, 0.1° grid scale is a two-stage problem:

  (a) Binary:    Does this cell burn at all this month?
  (b) Regression: If it burns, how much area (km²) is consumed?

Prior work (e.g., the QRF + logistic + RF pipeline of Barbero et al.) addresses
both stages, but treats them as independent chained models and relies on
hand-crafted spatial aggregates (fixed 3×3 neighborhood statistics) and static
lag features to represent temporal antecedents.

This work proposes a novel end-to-end framework that:
  1. Learns spatial structure (which neighbors matter, and how much) rather than
     fixing it to a 3×3 window.
  2. Learns temporal drought accumulation dynamics from raw monthly sequences
     rather than a fixed set of scalar lag features.
  3. Optimizes the binary and regression heads jointly through a shared latent
     representation (hurdle structure).
  4. Provides calibrated uncertainty on the burn probability via split-conformal
     prediction, rather than uncalibrated probabilities.

These four contributions are independent and additive: each can be ablated by
flipping a single flag in the configuration.


2. DATASET
────────────
Source:  GRIDMET (daily gridded meteorological data for CONUS)
Period:  1991–2024 (water years)
Domain:  California (lat 32.6–42.0°, lon -124.4 – -116.0°)
Grid:    0.1° conservative regrid → 2,296 cells
Panel:   Each cell × each month → 661,248 rows (perfectly balanced: 288 months/cell)

Target variables:
  burned          := (burned_area_km2 > 0)  [binary, 1.0% positive rate]
  log_burned_area := log1p(burned_area_km2) [continuous, positives only]
  burned_area_km2 := raw km² burned         [continuous, raw scale]

Class imbalance: 1 burned : 98.5 unburned  →  requires class weighting / hurdle design.

Feature groups (79 total):
  1. Standard means       (12): temperature, precipitation, humidity, fuel moisture,
                                energy release component, VPD, burning index
  2. Wind                  (4): u/v components, speed mean/max
  3. SPEI multi-window     (4): 30/90/180/270-day drought index
  4. Daily extremes        (5): consecutive dry/hot days, p95 values
  5. Climate anomalies     (5): temperature, max temp, RH, VPD, precipitation
                                 vs. 1991–2000 climatology baseline
  6. Fuel moisture lags    (6): fm100 and fm1000, 1–3 month lags
  7. Neighborhood 3×3     (10): mean/min/max aggregates for fm100, fm1000, VPD, ERC, BI
  8. Antecedent windows   (11): pr_avg 1–3 mo, spei30d_avg 1–6 mo, tmean_avg 1–2 mo
  9. Fire history          (2): cumulative burn frequency, burned in prior water-year flag
 10. Vegetation            (7): 6 binary cover-type dummies + ecoregion (encoded)
 11. LAI                   (4): leaf area index, 6-mo avg, neighborhood sums
 12. Terrain               (2): mean and max slope
 13. Infrastructure        (7): road, power-line, pole, tower, transformer densities
                                 + population density


3. SPLIT STRATEGY (configurable)
──────────────────────────────────
Standard random CV introduces two sources of leakage in spatiotemporal panels:
  (i)  Temporal leakage: future years in training set, past years in test set
  (ii) Spatial leakage: geographically adjacent cells in both train and test

This framework enforces a DOUBLE HOLDOUT:

  Temporal holdout (default: last 4 water-years = 2021–2024):
    - Selected because 2020–2021 were record-breaking fire seasons.
    - Rows with water_year >= cutoff are excluded from training entirely.
    - Represents out-of-time (OOT) generalization.

  Spatial OOD holdout (default: 15% of grid cells in contiguous lat/lon blocks):
    - Grid cells are grouped into blocks of `spatial_block_size` degrees.
    - A random fraction of blocks is withheld as the spatial OOD test set.
    - Rows belonging to held-out cells are excluded from training.
    - Represents geographic generalization (unseen regions).

  Validation set (default: 2 years before temporal test cutoff):
    - Used for LightGBM early stopping and conformal calibration.
    - Excluded from spatial OOD test to keep splits clean.

  Training set = all rows not in temporal test, not in spatial OOD, not in val.

Key configuration parameters:
  temporal_test_years  : int   (default 4)
  temporal_val_years   : int   (default 2)
  spatial_test_frac    : float (default 0.15, i.e., 15% of blocks)
  spatial_block_size   : float (default 3.0 degrees)
  cv_n_folds           : int   (default 5, for temporal CV within training data)


4. BASELINE: LIGHTGBM HURDLE MODEL
────────────────────────────────────
Two independently trained gradient-boosted tree models:

  Stage 1 — Binary LightGBM classifier
    Input:   all 79 tabular features
    Target:  burned (0/1)
    Handling imbalance: class_weight="balanced" (effective pos_weight ≈ 98.5)
    Threshold selection: calibrated via conformal prediction on validation set
                         (see Section 6), or via recall-targeting fallback

  Stage 2 — Regression LightGBM (hurdle)
    Input:   all 79 tabular features
    Target:  log_burned_area (continuous)
    Training: only on rows where burned == 1 (hurdle structure)
    Inference: predict log_area only for cells where Stage 1 predicts burned

Rationale for LightGBM as baseline:
  - Tree-based models handle multicollinearity (heavy within-category correlations)
    without feature selection preprocessing.
  - Gradient boosting is the current state-of-practice for tabular fire data.
  - Provides a strong, well-calibrated benchmark that the novel model must exceed.

Rationale for the hurdle formulation (response to potential reviewer challenge):
  The two-stage hurdle structure is the established statistical treatment for
  zero-inflated continuous outcomes. Burned area is a canonical example: the
  ignition process (whether a fire starts) and the spread process (how much area
  burns) are governed by different physical mechanisms and should not be modeled
  with a single regression that conflates them.

  Domain precedent:
    - Preisler et al. (2004, Int. J. Wildland Fire) — hurdle model for wildfire
      ignition and growth in the western US.
    - Preisler et al. (2011, Int. J. Wildland Fire) — extended hurdle approach
      for seasonal fire probability and area burned.
    - Cragg (1971, Econometrica) — foundational two-part model for zero-inflated
      continuous data.

  Empirical justification (ablation study, Table X):
    Three variants are compared on temporal-OOT and spatial-OOD test sets:
      (A) Binary-only:     Stage 1 classifier with no regression head.
                           Measures classification performance, but cannot
                           estimate burned area → regression metrics undefined.
      (B) Regression-only: Direct LightGBM regressor on all cells; binary
                           prediction derived by thresholding predicted log-area.
                           Conflates ignition probability with spread magnitude.
      (C) Hurdle (ours):   Stage 1 gates Stage 2; regressor trained only on
                           burned cells → cleaner signal, better RMSE.

    Results show that (C) improves PR-AUC over (A) by retaining area-based
    signal for ranking, and improves RMSE over (B) by isolating the regression
    task to cells where the physical process is active. This validates the
    hurdle structure empirically rather than relying solely on domain convention.


5. NOVEL FRAMEWORK: SPATIOTEMPORAL NEURAL HURDLE
──────────────────────────────────────────────────
5.1 Overview

The novel model replaces the two-stage LightGBM pipeline with a single neural
network that produces both binary and regression outputs from a shared latent
representation. The shared encoder has three components:

  (A) Static MLP encoder        →  z_static  (H-dim)
  (B) Temporal GRU encoder      →  z_temp    (H-dim)   [ablatable]
  (C) Soft graph attention (GAT) →  z_spatial (H-dim)   [ablatable]

All three are concatenated, passed through a fusion MLP, and decoded by:
  - Binary head:     σ(W · z) → P(burned)
  - Regression head: ReLU-MLP → log_burned_area

Loss function (joint, single backward pass):
  L = BCE_loss(logit, y_binary; pos_weight)  +  λ · MSE_loss(reg[pos], y_reg[pos])

Where λ = 0.5 balances binary and regression objectives. The regression loss
is computed only over ground-truth positive cells (true hurdle structure).


5.2 Component A: Static MLP Encoder

Encodes all 79 tabular features per row through two hidden layers (H units each,
ReLU activations, dropout). This is equivalent to the input to any standard MLP
classifier and serves as the base representation.

  Input:   (B, 79)  — batch × features
  Output:  (B, H)


5.3 Component B: Temporal GRU Encoder

Motivation: The 8 antecedent features (e.g., spei30d_avg1–6, pr_avg1–3) are
hand-crafted scalar summaries of recent climate history. A GRU can learn
arbitrary nonlinear accumulation functions over the raw temporal sequence,
including asymmetric drought build-up vs. recovery dynamics that scalar lags
cannot capture.

Design:
  - For each grid cell, store its full monthly climate time series as a
    (N_cells × T_all × n_temp_feat) array pre-loaded to GPU.
  - At inference time for row i, look up the cell's sequence up to the
    previous `temporal_lookback` months (default: 6).
  - Feed the (B, T, n_temp_feat) tensor through a multi-layer GRU.
  - Use the final hidden state as z_temp.

Temporal features used in the sequence (10):
  vpd, erc, bi, fm100, fm1000, pr, tmmx, tmmn, spei30d, spei90d

  Input:   (B, T, 10)  — batch × lookback months × features
  Output:  (B, H)

Ablation: set  use_temporal_gru = False  in CFG to disable.


5.4 Component C: Soft Graph Attention (Learned Spatial Aggregation)

Motivation: The 10 neighborhood features in the dataset use a fixed 3×3
spatial window with fixed aggregation (mean/min/max). This cannot adapt to
non-isotropic fire spread patterns or to heterogeneous landscapes where the
relevant spatial context may be directional (e.g., prevailing winds) or vary
by fuel type.

Design:
  - Construct a k-nearest-neighbor graph (default k=8) over the 2,296 grid
    cells using their lat/lon coordinates.
  - Each cell has a learnable embedding E_i ∈ R^H (nn.Embedding).
  - For each sample in a batch, look up the cell's k neighbor embeddings.
  - Apply multi-head scaled dot-product attention:

      Q = W_q · E_self              (B, 1, H)
      K = W_k · E_neighbors         (B, k, H)
      V = W_v · E_neighbors         (B, k, H)
      α = softmax(Q·Kᵀ / √d)       (B, n_heads, 1, k)
      z_spatial = α · V             (B, H)

  - The attention weights α are interpretable: they reveal which geographic
    neighbors contribute most to the burn prediction for each cell.

  Input:   cell index (B,)
  Output:  z_spatial (B, H)

  Key difference from fixed neighborhood: the model can learn that fire risk
  at a given cell is most strongly influenced by upwind neighbors (high VPD,
  low fm100) even if they are not the geometrically closest cells.

Ablation: set  use_spatial_attn = False  in CFG to disable.


5.5 Fusion & Dual Heads

  z_fused = Fusion_MLP( cat(z_static, z_temp, z_spatial) )   →  (B, H)

  Binary head:     P(burned)    = σ( W_bin · z_fused )
  Regression head: log_area     = ReLU-MLP(z_fused) → scalar

At training time, both heads are optimized simultaneously. At inference:
  - P(burned) → apply conformal threshold τ → binary prediction
  - log_area  → expm1(·) → burned area in km² (only for predicted-burned cells)


6. CONFORMAL PREDICTION (CALIBRATED UNCERTAINTY)
──────────────────────────────────────────────────
Standard ML models output uncalibrated probabilities. For fire risk communication,
agencies need a stated confidence level: "we predict this cell burns with ≥ 90%
coverage guarantee."

Split Conformal Prediction procedure:
  1. Reserve a calibration split (here: the validation set).
  2. For each calibration sample i with true label y_i ∈ {0,1}:
       nonconformity score  s_i = 1 − ŷ[y_i]
       (i.e., 1 − p̂_burned  if y_i=1;  p̂_burned  if y_i=0)
  3. Let τ = quantile(s_i, ⌈(1−α)(n+1)/n⌉)  for target coverage 1−α.
  4. At test time: predict BURNED if  p̂_burned ≥ 1 − τ.

Coverage guarantee: P(y_i ∈ Ĉ) ≥ 1−α for exchangeable (i.i.d.) data.
Note: exchangeability is violated in spatiotemporal settings; coverage is
approximate and reported empirically on both OOT and spatial OOD sets.

Default: 90% coverage (conformal_coverage = 0.90).
Output: τ, empirical positive-class coverage on each test set.


7. EVALUATION PROTOCOL
────────────────────────
7.1 Binary classification metrics (computed on all splits)
  PR-AUC       : primary metric (robust to heavy class imbalance)
  ROC-AUC      : secondary (inflated by true negatives, but expected by reviewers)
  F1 @ τ       : harmonic mean of precision & recall at conformal threshold τ
  Precision @ τ: fraction of predicted positives that are true positives
  Recall @ τ   : fraction of true fires that are detected

7.2 Regression metrics (computed on all splits, log-space targets)
  RMSE         : root mean squared error in log-space
  MAE          : mean absolute error in log-space
  R²           : coefficient of determination
  log-RMSE     : RMSE after back-transforming via expm1, then re-logging
                 (penalizes large magnitude errors in original scale)

7.3 Test splits evaluated
  Val                : in-distribution (same years, all cells) — sanity check
  Temporal OOT       : last 4 water-years (2021–2024), all cells
  Spatial OOD        : held-out 15% of grid-cell blocks, all years

7.4 Ablation study design
  Run §6 with the following CFG combinations to isolate each component:

  Label           | use_spatial_attn | use_temporal_gru
  ────────────────|──────────────────|─────────────────
  Static-only MLP |      False       |     False
  + GRU           |      False       |     True
  + GAT           |      True        |     False
  Full model      |      True        |     True   (default)

  Each ablation is compared against the LightGBM baseline on PR-AUC and
  log-RMSE on both temporal OOT and spatial OOD test sets.

11. CITATION / NOVELTY CLAIM SUMMARY
──────────────────────────────────────
This framework makes four independently testable methodological contributions
relative to existing wildfire ML pipelines:

  [C1] End-to-end joint hurdle model vs. independent chained models
       → Gradient signal from both binary and regression heads trains a single
         shared representation, allowing the model to learn features that are
         jointly predictive of ignition AND severity.

  [C2] Learned spatial aggregation via soft-GAT vs. fixed 3×3 window aggregates
       → The model learns which geographic neighbors are relevant, adapting to
         prevailing wind direction, fuel connectivity, and topographic barriers.
         The attention weights provide interpretable spatial influence maps.

  [C3] Sequential temporal encoding via GRU vs. scalar lag features
       → Drought memory is modeled as a learned nonlinear function of the raw
         climate sequence, capturing asymmetric accumulation/recovery dynamics
         that fixed-window averages and scalar lags cannot represent.

  [C4] Conformal prediction for calibrated burn probability sets
       → Replaces uncalibrated point probabilities with prediction sets that
         carry a formal coverage guarantee, directly useful for operational
         risk threshold communication.

  [Eval] Rigorous double-holdout evaluation protocol
       → Independent temporal OOT and spatial OOD test sets expose the
         optimism bias of random CV and of temporal-only holdouts.
         This is a methodological contribution applicable to any
         spatiotemporal ML benchmark in environmental science.
